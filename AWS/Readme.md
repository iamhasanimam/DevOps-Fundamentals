# AWS Cloud Practitioner Essentials – Learning & Documentation  

🚀 This repository documents my journey through [AWS Cloud Practitioner Essentials](https://skillbuilder.aws/learn/94T2BEN85A/aws-cloud-practitioner-essentials/8D79F3AVR7) on AWS Skill Builder.  

The goal is to **build strong foundational knowledge of AWS services, global infrastructure, pricing models, and the Well-Architected Framework** while capturing structured notes and hands-on exercises.  
---

## 📌 Objectives  
- Understand **AWS Cloud concepts** and core services.  
- Explore **compute, storage, databases, networking, and security** offerings.  
- Learn **global infrastructure**: Regions, Availability Zones, Edge locations.  
- Apply **Well-Architected Framework** to real-world cloud adoption.  
- Gain awareness of **AI/ML, analytics, and serverless services**.  
- Prepare for the **AWS Certified Cloud Practitioner exam**.  

---
